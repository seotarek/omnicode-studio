# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

OmniCode Studio processes data entirely client-side. However, if you discover any vulnerability relating to SVG injection (XSS via malicious input payloads), sanitization escapes, or denial of service in the regex parsers:

1. **Do not open a public issue.**
2. Send an email to security@seotarek.com or contact via GitHub Security Advisories.
3. Include steps to reproduce and a proof-of-concept payload.
4. We acknowledge reports within 24 hours and aim to release patches within 72 hours.
